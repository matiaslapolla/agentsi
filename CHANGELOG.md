# Changelog

## 0.2.0 - first public version

- Meetings of role agents with cited minutes, priorities, decisions and marks.
- The `/agentsi` front desk, the roles and the MCP server as a Claude Code plugin.
- Per-product briefs, rosters, overlays and agent memory that the owner can audit.
- Reflection that curates memory and proposes prompt changes, gated by a replay.
- Stories mode: a story session writes code on a `story/*` branch in a sandbox, with a cost cap.
- A local web app for the minutes, the calls, the memory and the stories.
- Optional call audio with Kokoro voices.
- `agentsi doctor` checks the tools that AgentSI needs.
- The data root keeps the registry and the workspace outside the code checkout.
